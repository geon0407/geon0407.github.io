공용 PC에서는 기억하지 마세요. 기억하지 않으면 이 탭을 닫을 때 토큰이 지워집니다.

처음 한 번 준비하기
  1. 새 저장소 만들기에서 이름을 blog-studio-data로, 공개 범위를 Private으로 만듭니다. 내용은 비워둬도 됩니다.
  2. Fine-grained 토큰 만들기에서
    • Expiration: 90일 정도 (만료되면 새로 만들어 다시 연결)
    • Repository access: Only select repositories → geon0407.github.io, blog-studio-data
    • Permissions → Repository permissions → Contents: Read and write (Metadata는 자동으로 Read)
    를 고르고 생성한 토큰(github_pat_…)을 위에 붙여넣습니다.
  3. 토큰은 GitHub 외에는 어디에도 보내지 않습니다. 토큰이 유출됐다고 생각되면 GitHub 설정에서 즉시 삭제하세요.
